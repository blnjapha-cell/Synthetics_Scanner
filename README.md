# Synthetics Predictor

A professional trading analysis platform for [Deriv](https://deriv.com) synthetic indices.  
Real-time signals powered by RSI, MACD, and Smart Money Concepts (SMC) strategy scoring.

---

## How to run the app

This app is made of two plain HTML files — no installation, no build step, no server required.

### Option 1 — Open directly in your browser (simplest)

1. Download or clone this repository
2. Double-click **`index.html`** to open it in your browser

That's it. The app loads instantly.

### Option 2 — Serve locally (recommended for WebSocket to work fully)

Some browsers block WebSocket connections from `file://` URLs. Use a local server instead:

**With Python (built into most computers):**
```bash
# Navigate to the folder
cd Synthetics_Scanner

# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```
Then open **`http://localhost:8080`** in your browser.

**With Node.js:**
```bash
npx serve .
```
Then open the URL it prints (usually `http://localhost:3000`).

### Option 3 — GitHub Pages (share with anyone)

1. Go to your repository on GitHub
2. Click **Settings → Pages**
3. Under "Source", select **`main` branch** and click **Save**
4. GitHub gives you a public URL like `https://blnjapha-cell.github.io/Synthetics_Scanner/`

## Logging in

When you open the app you will see a login screen asking for a **Deriv API token**.

### How to get a Deriv API token

1. Log in to your Deriv account at [app.deriv.com](https://app.deriv.com)
2. Go to **Account Settings → API Token**
3. Create a new token with **Read** and **Trade** permissions
4. Copy the token and paste it into the app's login screen

### App ID (optional)

Leave the App ID field blank to use the default (`1089`).  
If you have registered your own app on Deriv, enter your own App ID.

### No Deriv account?

The app automatically falls back to **Demo Mode** if it cannot connect to Deriv.  
Demo Mode generates simulated market data so you can explore all features without an account.

## SMC Grade column

The Asset Analysis table includes an **SMC Grade** column which scores each asset using Smart Money Concepts:

| Grade | Score | Meaning |
|---|---|---|
| **A+** | 6/6 | All SMC conditions met — strongest signal |
| **A** | 5/6 | Near-perfect SMC setup |
| **B** | 4/6 | Moderate SMC confirmation |
| **No Trade** | < 4 | Insufficient SMC evidence — stay out |

The SMC analysis runs 6 checks: equal highs/lows (liquidity pools), wick sweep, displacement + break of structure, order block identification, pullback into order block, and direction confirmation.
