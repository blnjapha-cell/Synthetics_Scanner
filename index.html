Documentation

API integration and model descriptions

WebSocket API Integration

The application connects to Deriv's WebSocket API for real-time market data.

wss://ws.derivws.com/websockets/v3?app_id={APP_ID}

Connection endpoints:

  • authorize - Authenticate with API token
  • ticks - Subscribe to tick data
  • ohlc - Subscribe to candlestick data
  • proposal - Get trading proposals

Prediction Models

LSTM (Long Short-Term Memory): Deep learning model for capturing temporal patterns in price sequences.

Random Forest: Ensemble learning method for classification and regression.

GARCH: Statistical model for forecasting volatility.

Signal Generation

Signals are generated based on:

  • Price momentum indicators (RSI, MACD)
  • Volatility metrics (ATR, Bollinger Bands)
  • Pattern recognition (candlestick formations)
  • Machine learning predictions

Confidence threshold: >70% for BUY/SELL signals

Risk Parameters

Maximum position size: 5% of account balance

Maximum drawdown limit: 20%

Stop loss default: 10 pips

Take profit default: 20 pips
